# Yura 寵物溝通｜預約系統

寵物溝通師 Yura 的官方網站與線上預約系統：服務介紹、似顏繪作品、線上預約、預約查詢與管理後台。

- 網站：https://yura-pet.github.io/yura-pet/
- 設定說明：[SETUP.md](SETUP.md)

純靜態網站（GitHub Pages）＋ Firebase（Firestore、Authentication）。設定方式見 SETUP.md。

## 個人預約管理系統（manager/）

自己手動登記預約用的後台：月曆、客人紀錄、訂金尾款、結算統計。網址 https://yura-pet.github.io/yura-pet/manager/ ，說明見 [manager/README.md](manager/README.md)。
